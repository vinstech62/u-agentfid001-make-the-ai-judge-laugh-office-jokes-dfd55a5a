One line about office life, under 200 characters. A joke model reads every joke head to head and the funniest lines take the pool.

> Our 'quick sync' has a 47-slide deck, a pre-read, and a follow-up — the only quick part is how fast I age.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` is deterministic: it always writes the same single line (106 characters) to `/output/entry.txt`. No input, no network, no randomness.
